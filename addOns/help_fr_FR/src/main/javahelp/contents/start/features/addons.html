Accessoires

Les extensions ajoutent des fonctionnalités supplémentaires à ZAP.
Elles ont un accès complet aux composants internes de ZAP et peuvent ainsi fournir de nouvelles fonctionnalités très puissantes.
Vous pouvez installer dynamiquement des extensions depuis la plateforme d’extensions en ligne via la boîte de dialogue Gérer les extensions.
Vous pouvez généralement ajouter et supprimer des extensions depuis l’interface utilisateur de ZAP sans avoir à redémarrer l’application.

Les extensions peuvent fournir une aide contextuelle qui est intégrée dynamiquement au fichier d’aide.
Si vous consultez cette page depuis un fichier d’aide de ZAP (plutôt qu’en ligne), toutes les pages d’aide associées aux extensions que vous avez installées seront disponibles ici.

Un statut est attribué aux extensions, qui peut être l’un des suivants :
     Releasequi indique qu’elles ont un statut élevé et sont adaptées à leur usage
     Bêtaqui indique qu’elles ont un statut satisfaisant, mais peuvent être incomplètes ou nécessiter des tests supplémentaires
     Alphaqui indique qu’elles sont à un stade précoce de développement

Emplacement des extensions disponibles pour ZAP

Pour qu’une extension soit disponible dans ZAP, elle doit se trouver dans l’un des emplacements suivants :
  • Le répertoire plugin situé dans le dossier d'installation de ZAP ;
  • Le répertoire plugin situé dans le dossier utilisateur de ZAP.
